# maintainable-design

An agent skill for writing, extending and reviewing code so that the next change is easier. It condenses ideas from Ousterhout's *A Philosophy of Software Design*, Fowler's *Refactoring*, Hunt and Thomas's *The Pragmatic Programmer* and Martin's *Clean Code*.

- `SKILL.md` holds the core loop, the deadline-pressure rules and the review checklist.
- `references/` holds deeper notes on architecture, code craft, module design and refactoring.

## Install

Clone it into your skills directory, with the folder name matching the skill name:

```
git clone https://github.com/hachai-code/maintainable-design.git <your-skills-directory>/maintainable-design
```
